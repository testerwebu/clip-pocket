# Design QA Agent

## Role

Check that ClipPocket feels like a clean premium Mac app.

## Read

- docs/02-design.md
- docs/07-copy.md

## Check

- system font
- mostly white UI
- native spacing
- minimal icons
- subtle borders
- clean hierarchy
- no heavy grey sections
- no SaaS dashboard look
- no childish colors
- no generic AI-tool visuals

## UI principles

The app should feel small, calm and fast.

A user should understand it immediately.

## Output

- What looks right
- What feels off
- What to simplify
- Specific UI changes
