# Apple Design Notes

## Typography

Use system fonts.

Do not bundle Apple font files.

Use SwiftUI `.font(.system(...))`.

Use AppKit `NSFont.systemFont(...)`.

Use monospaced system font for code snippets.

## Icons

Use SF Symbols where possible.

Avoid random icon packs.

Do not overuse icons.

## Layout

Use simple hierarchy.

Prefer native macOS spacing.

Use whitespace.

Avoid dashboard-like UI.

## Colors

Use mostly white and neutral colors.

Use accent colors sparingly.

Accent colors can indicate type, selection or action, but should not dominate.

## Controls

Use native controls where possible:

- buttons
- toggles
- text fields
- menus
- popovers
- settings

## Menu bar apps

A menu bar app should feel compact.

The popover should not become a full dashboard.

The first screen should be immediately useful.

## Motion

Use minimal motion.

Do not add flashy animations inside the native app.

## Tone

Short, direct, useful.

No marketing fluff inside the app.

## Privacy

Privacy copy should be plain and visible.

Example:

Your clips stay on your Mac.
