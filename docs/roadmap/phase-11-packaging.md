# Phase 11 — Packaging

## Goal

Prepare ClipPocket for external testing and paid download.

## Read before work

- docs/01-product.md
- docs/05-privacy.md
- docs/06-pricing.md

## Tasks

- Prepare release build.
- Prepare signing plan.
- Prepare notarization plan.
- Prepare DMG or ZIP distribution.
- Document installation flow.
- Document local data storage paths.
- Document known limitations.
- Prepare support email placeholder.
- Consider Sparkle later, but do not add unless requested.

## Do not

- Do not build license system unless explicitly requested.
- Do not add account system.
- Do not add cloud sync.
- Do not add subscription billing.

## Acceptance criteria

- Release build can be created.
- App can be distributed for testing.
- Install flow is understandable.
- Privacy behavior is documented.
