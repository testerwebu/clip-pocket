# Phase 12 — Landing Page

## Goal

Build the landing page after the native V0.1 works.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- App Router
- Vercel target

## Read before work

- docs/01-product.md
- docs/02-design.md
- docs/06-pricing.md
- docs/07-copy.md

## Page structure

1. Header
2. Centered hero
3. Demo loop
4. How it works
5. Clip types section
6. Search section
7. Privacy section
8. Pricing
9. FAQ
10. Final CTA
11. Footer

## Hero

Headline:

Keep every clip in one tiny pocket.

Subheadline:

A tiny Mac app that keeps every copied text, link, color and snippet in one clean local pocket.

CTA:

Get lifetime access

Microcopy:

No subscription. No account. Your clips stay on your Mac.

## Style

- white
- minimal
- Apple-like typography
- lots of whitespace
- black primary CTA
- subtle colorful accent only in CTA/icon
- no grey-heavy sections
- no SaaS dashboard look

## Do not

- Do not promise unbuilt features.
- Do not create fake testimonials.
- Do not add backend.
- Do not add auth.
- Do not add dashboard.

## Acceptance criteria

- Landing is fast.
- Landing is mostly static.
- Landing uses real product visuals.
- Pricing is clear.
- Privacy message is clear.
- CTA can link to Stripe/payment later.
