# Phase 10 — Polish

## Goal

Make ClipPocket feel premium enough to sell.

## Read before work

- docs/02-design.md
- docs/07-copy.md
- docs/05-privacy.md

## Tasks

- Refine spacing.
- Refine typography.
- Refine empty states.
- Refine clip rows.
- Refine filters.
- Refine quick actions.
- Refine settings.
- Add loading/error states where needed.
- Add subtle hover/selection states.
- Verify light mode.
- Verify dark mode only if supported.
- Remove visual clutter.

## Design rules

- mostly white
- system font
- subtle borders
- minimal icons
- compact but readable
- no SaaS dashboard
- no loud gradients

## Do not

- Do not add new product scope.
- Do not add cloud.
- Do not add landing page yet unless Phase 12 is reached.

## Acceptance criteria

- App feels native.
- UI is calm and clean.
- App is easy to understand.
- App builds and launches.
