# Phase 01 — Menu Bar Shell

## Goal

Create the basic menu bar app shell.

## Read before work

- docs/02-design.md
- docs/03-architecture.md
- docs/07-copy.md

## Tasks

- Add menu bar icon.
- Add menu bar popover.
- Add empty state.
- Add settings window shell.
- Add basic app menu actions if needed.
- Keep UI white, minimal and native.

## Empty state copy

Your pocket is empty.

Copy something anywhere on your Mac and it will appear here.

## Do not

- Do not implement clipboard watching.
- Do not implement local database.
- Do not implement search.
- Do not implement OCR.
- Do not add landing page.

## Acceptance criteria

- ClipPocket appears in the macOS menu bar.
- Clicking the icon opens a small popover.
- Empty state is visible.
- Settings window can open.
- App builds and launches.
