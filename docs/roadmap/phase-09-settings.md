# Phase 09 — Settings

## Goal

Create minimal useful settings.

## Read before work

- docs/02-design.md
- docs/05-privacy.md
- docs/07-copy.md

## Tasks

Add settings for:

- launch at login
- pause clipboard monitoring
- max history size
- ignore duplicate clips
- ignore transient clipboard content
- ignore concealed clipboard content
- clear history
- privacy note
- about/version

## Privacy note

ClipPocket stores your clipboard history locally on your Mac.

No clips are uploaded.

No account is required.

## Do not

- Do not create a large dashboard.
- Do not add account settings.
- Do not add cloud sync settings.
- Do not add billing settings in V0.1.

## Acceptance criteria

- Settings are minimal and native.
- User can pause monitoring.
- User can clear history.
- User can see privacy note.
- App builds and launches.
