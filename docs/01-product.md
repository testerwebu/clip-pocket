# Product

## Product name

ClipPocket

## One-line promise

Keep every clip in one tiny pocket.

## Short tagline

Copy. Forget. Find it later.

## What ClipPocket is

ClipPocket is a tiny native macOS clipboard utility that saves copied items locally and makes them easy to find later.

It lives in the macOS menu bar.

The user copies something anywhere on their Mac, then ClipPocket quietly keeps it in a clean, searchable pocket.

## What ClipPocket is not

ClipPocket is not:

- a SaaS product
- a cloud clipboard
- a team tool
- a web dashboard
- a notes app
- a snippet expansion app in V0.1
- an automation platform
- a subscription-first product
- a ClipBook clone

ClipPocket can learn from other clipboard managers, but it must remain its own product.

## Primary user

A Mac user who copies many things during the day and loses them.

Examples:

- founders
- designers
- marketers
- developers
- creators
- consultants
- students
- people working with ChatGPT, Notion, Slack, Gmail, Figma, Xcode, VS Code, Linear, Google Docs and browsers

## Main pain

The user copied something useful but later cannot find it.

Common examples:

- copied a link and lost it
- copied an email address and forgot where it came from
- copied a color value and needs it again
- copied code from documentation
- copied something from a specific app and wants to find it again

Post-V0.1 examples:

- copied HTML/rich text
- copied an image
- copied a file in Finder

## Core value

ClipPocket makes clipboard history feel like a clean local pocket.

The user can:

- open the menu bar pocket
- search old clips
- filter by type
- copy old clips back
- pin important clips
- delete private clips
- keep everything local

## V0.1 clip types

V0.1 should support only text-based clipboard items:

- plain text
- links / URLs
- email addresses
- color values, especially HEX, RGB and HSL
- code snippets stored as plain text

In V0.1, code means plain text that looks like code.

## Post-V0.1 clip types

These are future features and must not be implemented in the first usable version:

- HTML / rich text
- images
- files copied from Finder
- thumbnails
- OCR

## Core actions

Every clip should support some or all of these actions depending on type:

- copy back to clipboard
- copy as plain text
- preview
- pin / unpin
- favorite / unfavorite
- delete
- search
- filter by type

Post-V0.1 actions:

- reveal in Finder for files
- preview rich content, images and files

## Local-first promise

Copied content should stay on the user’s Mac.

No copied content should be uploaded in V0.1.

No account should be required.

No cloud sync should exist in V0.1.

## Pricing direction

Simple lifetime pricing.

Preferred first version:

- $29 founding lifetime license
- one personal license
- no subscription
- no account

Do not build licensing infrastructure in V0.1 unless explicitly requested.

## Positioning

ClipPocket should feel like a small premium Mac utility.

It should be more native, lighter and cleaner than heavy clipboard managers.

It should not look like a SaaS dashboard.

## Success criteria

V0.1 is successful if a user can:

1. Launch ClipPocket.
2. See it in the menu bar.
3. Copy text, links, emails, colors and code snippets stored as plain text.
4. Find old clips later.
5. Copy an old clip back to the clipboard.
6. Pin important clips.
7. Delete private clips.
8. Search locally.
9. Trust that clips stay on their Mac.
