# ClipPocket Web

Landing page for ClipPocket.

This should be built only after the native macOS MVP works.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- App Router
- Vercel target

## Role

The landing page sells the real app.

It should not promise features that do not exist.

## Style

- white
- minimal
- Apple-like
- centered hero
- large typography
- black primary CTA
- subtle accent colors
- lots of whitespace

## Hero

Headline:

Keep every clip in one tiny pocket.

Subheadline:

A tiny Mac app that keeps every copied text, link, color, file and snippet in one clean local pocket.

CTA:

Get lifetime access

Microcopy:

No subscription. No account. Your clips stay on your Mac.

## Do not

- do not add auth
- do not add dashboard
- do not add database
- do not add CMS
- do not add backend unless explicitly needed later
